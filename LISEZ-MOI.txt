# GALERIE D'URVAL - MANUEL UTILISATEUR

## 🎨 INTRODUCTION
La Galerie d'Urval est une galerie d'art virtuelle en 3D développée avec A-Frame, permettant une immersion complète dans un espace d'exposition. Cette application offre deux modes d'utilisation : visiteur et administrateur.

## 👤 MODE VISITEUR (ÉLÈVE)

### Navigation dans la galerie
- **Déplacement** : Touches ZQSD ou flèches directionnelles
  - Z / ↑ : Avancer
  - S / ↓ : Reculer  
  - Q / ← : Tourner à gauche
  - D / → : Tourner à droite
- **Regarder autour** : Mouvement de la souris (cliquer-glisser)
- **Course** : Maintenir Shift pendant le déplacement pour accélérer

### Interaction avec les œuvres
- **Visualisation du cartel** : Cliquez gauche sur un tableau pour afficher les informations
  - Titre de l'œuvre
  - Nom de l'artiste
  - Description détaillée
- **Audio-description & Vidéo-description** : Si disponible, le lecteur apparaît automatiquement à gauche
  - ▶/⏸ : Lecture/pause
  - ⟲/⟳ : Reculer/avancer de 10 secondes
  - Curseur : Navigation dans la piste audio
  - 🔊 : Contrôle du volume
- **Plein écran** : Cliquez sur l'icône ⛶ dans le cartel pour voir l'œuvre en grand format
  - ✕ ou Échap : Fermer le plein écran

### Interface utilisateur
- **Panneau d'aide** : Apparaît au démarrage avec les contrôles de base
  - ✕ ou Échap : Fermer l'aide
- **Boutons admin** : Visibles en bas à gauche de l'écran
  - 🔒 Admin : Ouvrir la fenêtre de connexion
  - 🎨 Galerie : Ouvrir le panel de création de galerie

## 🔧 MODE ADMINISTRATEUR (ENSEIGNANT)

### Appuyez sur la touche ²
1. Cliquez sur le bouton 🔒 Admin en bas à gauche
2. Entrez le mot de passe (admin)
3. Cliquez sur Valider ou appuyez sur Entrée
4. Le bouton change d'apparence pour indiquer la connexion réussie

### Panel d'édition d'œuvre
Accessible en cliquant sur un tableau lorsque connecté en tant qu'admin.

#### Onglet Cartel
- **Titre** : Modifier le nom de l'œuvre
- **Artiste** : Modifier le nom de l'artiste
- **Description** : Modifier la description détaillée

#### Onglet Média
- **Aperçu actuel** : Voir le média actuellement associée
- **Changer l'image** : Télécharger une nouveau média
  - Après sélection, l'aperçu se met à jour immédiatement
  - Pour sauvegarder, utilisez le bouton "Sauvegarder"

#### Onglet Audio
- **Audio existant** : Voir et supprimer l'audio actuel
- **Téléversement** : 
  1. Sélectionner un fichier audio
  2. Cliquer sur "Télécharger audio-{N}.ext"
  3. Déplacer le fichier téléchargé dans le dossier `assets/audiodescription/`
  4. Rafraîchir la page pour prendre en compte le nouvel audio

#### Onglet Position & Taille
- **Position (X, Y, Z)** : 
  - X : Mouvement latéral (-20 à 20)
  - Y : Hauteur (0 à 7) 
  - Z : Profondeur (-20 à 20)
- **Rotation (Y)** : Rotation autour de l'axe vertical (-180° à 180°)
- **Échelle** : Taille relative (0.1x à 10x)
- **Bordure** : Épaisseur de la cadre en mètres (0.01m à 1m)

#### Sauvegarde
- Cliquez sur le bouton bleu "Sauvegarder" en bas pour enregistrer toutes les modifications
- Le bouton "✕" ferme le panel sans sauvegarder

### Panel de création de galerie
Accessible via le bouton 🎨 Galerie lorsqu'connecté en tant qu'admin.

#### Onglet Tableau
- **Nombre de tableaux** : Choisissez combien de tableaux afficher (le maximum conseillé étant 32)
  - Distribution équitable sur les 4 murs
- **Générer la galerie** : Crée la configuration sélectionnée
- **Ajouter un tableau** : Ajoute un nouveau tableau unique devant votre position actuelle

#### Onglet Réglages
- **Échelle des tableaux** : Taille globale de tous les tableaux
- **Épaisseur bordures** : Largeur uniforme de toutes les cadres
- **Hauteur Y** : Position verticale centrale de tous les tableaux
- **Espacement** : Distance équilatérale entre les tableaux sur chaque mur
- **Supprimer tous les tableaux** : Efface complètement la galerie actuelle


#### Onglet Configuration
- **Exporter la configuration** : Télécharge un fichier JSON contenant toutes les métadonnées
- **Importer une configuration** : Restaure une configuration depuis un fichier JSON

## ⚙️ PERSONNALISATION DE LA GALERIE

### Ajout manuel d'œuvres
Pour ajouter des œuvres sans passer par l'interface admin :
1. Placez vos images dans `assets/tableaux/` avec le nom `tableau-X.jpeg` ou `tableau-X.mp4` (X = numéro)
2. Placez vos audio dans `assets/audiodescription/` avec le nom `audio-X.mp3`
3. Placez vos cartels dans `assets/cartels/` avec le nom `cartel-X.json`
4. Sauvegarder les métadonnées modifiées (position, cartels) en écrasant `assets/tableaux/configuration.json`

### Vider le cache
- Pour vider le cache localStorage du navigateur (F12 ou Ctrl + Maj + J):
localStorage.clear();
location.reload();

### Pour les administrateurs
- Toujours sauvegarder après avoir effectué des modifications
- Exportez votre configuration depuis le mode admin pour modifier les métadonnées (configuration.json)
- Testez les changements en mode visiteur après édition
- Les fichiers uploadés doivent être placés manuellement dans les dossiers appropriés pour persister après rafraîchissement (autrement ils seront stockés temporairement dans votre navigateur)
